# Agentic AI

Exploring **LangChain, AI agents, and RAG (Retrieval-Augmented Generation)** with Python.

Experiments, notes, and small projects to learn how agentic AI systems work and how to integrate them into applications.


## 🧠 Topics

### LangChain & AI Agents

- LangChain fundamentals
- Prompt templates
- Chat models
- Chains and LCEL
- Tools and tool calling
- AI agents
- Agent memory
- LangGraph
- Agent workflows

### RAG

- Document loading
- Text splitting
- Embeddings
- Vector stores
- Retrieval
- Retrieval-Augmented Generation
- Building RAG applications

## 🛠️ Technologies

- Python
- [uv](https://docs.astral.sh/uv/)
- LangChain
- LangGraph
- LLM APIs
- Vector databases

## 🎯 Purpose

The goal of this repository is to learn by **building and experimenting**, starting with individual concepts and gradually combining them into complete AI workflows and applications.
